# TASK MASTER PRO

A professional, production-ready Task Management application developed with Flutter. It features a clean architecture combining real-time cloud synchronization, local data persistence, and interactive user interactions.

---

## 🚀 Key Features

* **Real-Time Synchronization:** Integrated with Firebase Firestore to ensure your tasks are seamlessly synced across devices instantly.
* **Offline Persistence:** Uses the `SharedPreferences` engine to save task matrices locally so your data is never lost, even without internet connectivity.
* **Task Reminders:** Features an integrated local notifications subsystem to alert users of upcoming task schedules.
* **Custom Interactive UI:** Showcases a custom animated splash screen and a clean, high-contrast Material 3 dark-themed workspace layout.
* **Asynchronous Web Orchestration:** Built-in network service layers capable of live asynchronous data fetching and parsing external JSON APIs dynamically.


## 🔧 Setup and Installation

To run this project locally on your machine, follow these steps:

1. **Clone the Repository:**
   git clone [https://github.com/aymenkhan1144/task_master_pro.git](https://github.com/aymenkhan1144/task_master_pro.git)

2. **Get Dependencies:**
   Navigate into the project directory and run:
   flutter pub get

3. **Firebase Configuration:**
   Ensure your google-services.json file is present inside the /android/app/ directory.

4. **Run the Application:**
   flutter run
